У лабораторній роботі було модернізовано застосунок EdoSign Lab-3, додавши можливість працювати з різними типами баз даних. Через конфігураційний файл реалізовано вибір одного з чотирьох провайдерів: SQLite, PostgreSQL, SQL Server або InMemory. Це дозволило перемикати БД без зміни програмного коду.

Для перевірки крос-платформної роботи застосунок було розгорнуто у віртуальній машині Ubuntu 22.04 за допомогою Vagrant. Автоматичне встановлення .NET, клонування репозиторію, відновлення залежностей і публікація забезпечувалися через Vagrantfile. Також у віртуальне середовище було перенесено реальну SQLite-базу, що дозволило зберегти всі наявні дані (клієнти, документи тощо).

Оскільки сервер автентифікації не був обов’язковою частиною перевірки, в застосунок додано автоматичну псевдо-автентифікацію, що давала змогу тестувати вкладки для авторизованих користувачів без окремого входу.

У результаті застосунок успішно запущено під Linux, дані коректно зчитуються, а всі функції (перегляд клієнтів, документів, завантаження файлів тощо) працюють у середовищі віртуальної машини. Це підтверджує виконання вимог роботи щодо багатопровайдерної БД та крос-платформного розгортання.
